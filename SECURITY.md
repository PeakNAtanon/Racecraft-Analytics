# Security Policy

Do not open a public issue for suspected credential exposure, unauthorized data access, or a vulnerability that could affect a deployed instance. Report it privately to the repository owner through the project contact channel and include only the minimum steps needed to reproduce it.

Do not include `.env` files, database dumps, provider tokens, FastF1 cache, or raw telemetry in reports. The project has no public bug-bounty program. Security fixes should include a regression test where practical and should be deployed before public disclosure.
